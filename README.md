# 🚀 Sales Rank

A modern, responsive web application built with **React JS** and **Tailwind CSS**.

## 📦 Technologies / tools Used
- ⚛️ **React JS** – UI library
- 🎨 **Tailwind CSS** – Utility-first CSS framework
- 🔣 **React Icons** – Icon library with popular icon packs
- 🖥️ **Visual Studio Code** - For Coding

---

### 1️⃣ Clone the Repository

1. git clone https://github.com/RoyNiloy40701/Sales-Rank.git
2. cd your-project


## 🛠️ Project Setup Instructions

1. Install Dependencies - npm install or yarn install
2. Set Up Tailwind CSS -
   1. npm install -D tailwindcss postcss autoprefixer
   2. npx tailwindcss init
3. Update tailwind.config.js - content: ["./src/**/*.{js,jsx,ts,tsx}"],
4. In src/index.css -  @tailwind base;
                       @tailwind components;
                       @tailwind utilities;

5. Install React Icons - npm install react-icons
6. Run the Project - npm start
